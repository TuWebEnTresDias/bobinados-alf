# Notas de implementación

- Sitio estático en la raíz de GitHub Pages. Usar rutas relativas para que funcione bajo `/bobinados-alf/`.
- Mantener las imágenes dentro de `assets/`; no enlazar los originales del chat ni otros recursos temporales.
- El contacto abre WhatsApp con un texto preparado. La página no almacena datos ni envía mensajes por su cuenta.
- Esta versión es un preview público: conservar `noindex` y excluirlo del sitemap hasta recibir aprobación para el lanzamiento.
- No agregar scripts de analítica, formularios o dependencias externas sin revisar el alcance y la configuración de privacidad.
