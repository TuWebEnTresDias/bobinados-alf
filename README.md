# Bobinados Alf

Sitio de preview personalizado para Bobinados Alf, construido sobre la demo de electricista y adaptado a bobinados y reparación de motores eléctricos.

- Las fotos del taller y los equipos fueron compartidas por el negocio, optimizadas y guardadas en `assets/`.
- El sitio no usa formularios, backend, librerías remotas ni analítica; las consultas se abren en WhatsApp para que la persona decida si las envía.
- La URL de preview conserva `noindex` y no incluye sitemap hasta la aprobación del sitio final.
